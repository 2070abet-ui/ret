## 0. 結論（先出し）

- 「キャッチーさ」と「誇張」は別物。**このサイトでクリックを稼ぐ有効なタイトルは「クエリ先頭一致＋具体性（軸・対象・数字）＋検証の約束」で、煽り・No.1・緊急性ではない**。
- 現行5本は「網羅型・無難型」に寄り、**タイトル後半がGoogleの切り詰めで読まれない想定**で設計されていない。ここは改善余地が確かにある。
- ただし**順位が38位（圏外）の現状では、タイトル改善は「上位に入ったときにクリックされる確率」を上げる下準備であり、表示・順位そのものを上げるものではない**（REAFFERM: 既存調査）。低コスト・誠実性を崩さない範囲で進める価値がある、という位置づけ。

## 1. リサーチ：有効なタイトルの条件

### 1.1 Google公式（一次情報・要約）
出典: https://developers.google.com/search/docs/appearance/title-link （2026-09-04取得）／SEO Starter Guide

| 公式の指針 | このサイトへの示唆 |
|---|---|
| titleリンクは「クリックするか否かを決める第一の情報」。ページごとに高品質な`<title>`を | titleは「地味でよい」のではなく**競合10件と並んだ1行**で勝負する場所 |
| 「説明的かつ簡潔に」。曖昧語（Home等）・冗長・長すぎを避ける | 網羅語（「◯◯・△△・□□まで解説」等）は削ってよい |
| `<title>`に長さ上限は無いが、**検索結果では端末幅で切り詰められる** | **伝えたい結論・差別化語はタイトルの前方へ**。末尾に載せても読まれない |
| 全ページ同じ文言（ブランド等）の繰り返しは冗長に見える | 「宅食図鑑」suffixは最小限に。タイトル本体で食い潰さない |
| Googleが自動でtitleを書き換えることがある（あくまで「指示」） | **本文（H1・先頭段落）と乖離する煽りtitleはGoogleに捨てられる**＝無駄になる |

### 1.2 業界で確立されたプラクティス（一般論・数値は「目安」）
- **クエリ語を先頭に置く**。完全一致に近いほど関連性シグナルと視認一致が取れる。
- **1ページ＝1意図**。複数クエリを1本で拾おうと網羅すると、どのクエリにも刺さらない中空タイトルになる（現行の弱点）。
- **「クリック後に得られる答えの輪郭」を予告する**（例:「◯◯で選ぶ」「◯◯の人が対象」「◯◯はいくら？」）。予告と本文の一致が直帰を防ぐ。
- 数字・条件は**実在するものだけ**（例: 初回3,799円・送料990円・16社）。偽の数字・「◯選」水増しは禁止（`ARTICLE_WRITING_PRINCIPLES` 6章）。
- 質問形は、ユーザーが実際に検索する疑問文（AEO/GEO）と相性がよい（6章で許可済み）。
- **日本タイトルの表示目安**: デスクトップで概ね**全角30〜37字前後**で切り詰めが始まり、モバイルではより短い。→ 差別化語は先頭〜冒頭25字以内に置くのが安全（「切り詰め」は端末幅依存のためコードで保証はできない。実測は後述§5）。

### 1.3 このサイト固有の制約（候補の設計条件）
1. **誠実性・恒久禁止が最優先**（`ARTICLE_WRITING_PRINCIPLES` 10章 / `UI_DESIGN_PRINCIPLES` 8章）:
   偽の緊急性・根拠のないNo.1・捏造・水増し数字は不可。★「おすすめ比較」のような、順位を付けていないのに「おすすめ」を匂わせる語もできるだけ避ける（候補で削除）。
2. **titleはH1・先頭段落と整合させる**（CTR_IMPROVEMENT_PLANで実装済みの方針。Google自動書き換え対策）。
3. **本文の実データと一致する数字のみ使う**: 掲載社数は 高齢者=5・デメリット=16・ダイエット=6・一人暮らし=5（実測確認済み）。
4. **記事が言っている「本命テーゼ」をタイトルに使える**（本文を裏返さない範囲のキャッチー化はここでしかできない）。
5. 年号直書きは使わない（鮮度ズレ防止の既存方針）。

## 4. 実装時の注意（承認後に適用する場合の設計条件）

1. **title変数・`<h1>`・meta description を同じ文言系で同期**する（ページ内の見え方とSERPを揃え、Googleの自動書き換え余地を減らす）。
2. **URL・canonical・パンくずは変更しない**（URL正規化済み。中身の書き換えのみ）。
3. タイトル本体は**目安で全角〜36字以内**を狙い、**差別化語（軸・対象・数字・テーゼ）を冒頭25字以内**に置く。末尾の「宅食図鑑」suffixは現行のまま（本体を短くして食い潰さない）。
4. 対象記事の**掲載社数（5/16/6/5）・主張が本文と一致**することを適用直前に突合する（本文データが先、タイトルは後追い）。
5. 1記事ずつ適用し、**複数記事で同じ語（後悔・選び方等）が集中しない**よう全体で重複チェックする。

## 5. 適用後の検証・測定方法（承認後・デプロイ後の手順）

1. `python tools/build.py`→本番HTMLでtitle/H1/desc反映を確認。
2. 表示・クリックはGSC Performanceで**クエリ別CTR・順位**を確認（順位20位前後に到達したクエリのページから効果を判定。2〜4週間）。
3. 表示幅の実測は、実ブラウザ（Playwright モバイル/PC）でSERP相当幅を再現して切り詰め位置を目視確認（コードでは保証不可のため）。
4. タイトルがGoogleに自動書き換えられた形跡（GSCのインプレッションに対するクリック等）があれば、本文との乖離がないか再点検。
