# 日本向けアフィリエイト事業 市場選定・競争優位性調査（2026年8月版）

調査日: 2026-08-26
調査主体: Claude Code（WebSearch/WebFetchによる一次・準一次情報調査）
凡例: **確認済み**=検索結果・公式ページ等で直接裏取りできた事実／**推測**=業界慣行・複数二次情報からの論理的推定／**確認不能**=本調査の範囲では特定できなかった（多くはASP会員ログイン後にしか見えない情報）

---

## 0. 調査の前提とモデル

狙うビジネスモデル：

```
既存ASP/EC/計測基盤
  → Claude Codeによる市場・案件・競合調査
  → 独自データの蓄積
  → 購買意思決定を支援するコンテンツ/ツール
  → アフィリエイトCV
  → 成果データ蓄積
  → Claude Codeによる分析・改善
  → 次のコンテンツ/案件選定
```

完全自動化ではなく、**人間が重要判断を行い、Claude Codeが調査・監視・下書き・比較表作成等の反復作業を代替する**モデル。「高単価」「検索ボリューム大」という単純基準ではなく、①競争密度 ②単価・収益性 ③購買意図 ④情報更新頻度 ⑤独自データ構築可能性 ⑥Claude Code適性 ⑦初期費用 ⑧初回CVの速さ ⑨AI検索耐性 の9項目で評価し、YMYL規制・大手独占・データ資産化不能性などがある場合は加重平均から追加減点した。

### 調査体制と限界（正直な申告）
本調査は5系統の並行Web調査（AI/SaaS・BtoB SaaS・サブスク・資格教育・転職／PC周辺機器・ガジェット・家電・カー用品・中古車・趣味ホビー／格安SIM・電力ガス・クレジットカード金融／旅行・ふるさと納税・宅配食・コスメ・ペット／新規ジャンル探索）に分けてWebSearch/WebFetchで実施した。**ASPへの実アカウントログインは行っていない**ため、各ASPの正確な単価表・承認率・独占案件・キャンペーン頻度の多くは「確認不能」である。数値は推測で埋めず、確認できた範囲・出典を明記した。参入判断の最終ステップでは、必ず各ASPに実アカウント登録し一次情報で再確認することを推奨する。

## 2. ジャンル別評価サマリー（9項目）

以下、各ジャンルの9項目評価を要約する。詳細な出典URL・確認/推測/確認不能ラベルの全文は本調査のリサーチログ（クラスタ別調査結果）に基づく。主要な出典は各項に記載した。

### 2.1 宅配食 / 食品宅配　総合75点

- **①競争密度**: 中〜低。SERP上位（bread-espresso.jp、麺屋武蔵運営メディア、マイベスト、GYRO HOLDINGS等）は本業と無関係な企業が運営する量産型オウンドメディアが多く、大手ポータル自社サイトの寡占ではない＝個人でも同種の戦い方で入り込める余地がある。
- **②単価**: 確認済み。nosh（ナッシュ）はA8.net/afbで提携可能、初回購入報酬 約3,500〜3,850円。ワタミの宅食ダイレクトはA8.netでセルフバック案件あり（初回申込＋2回目課金で5,000円、条件別途確認要）。食宅便（日清医療食品）もASP扱いあり。定額報酬型が多く単価が読みやすい。
- **③購買意図**: 「宅配食 比較 一人暮らし」「nosh ワタミの宅食 どっちが安い」等Commercial Investigation〜Transactional。
- **④更新頻度**: 高。メニュー入替、初回割引・送料無料キャンペーンが頻発（2026年にDELIPICKSが値下げ・送料変更を実施した事例を確認）。
- **⑤独自データ**: 高。メニュー別カロリー・塩分・糖質・価格DB、初回キャンペーン変遷DB、解約条件比較DBが構築可能。実食して一次情報化できる点が強み。
- **⑥Claude Code適性**: 高。メニュー・価格ページの定期取得→構造化→比較表自動更新、キャンペーン差分検知が容易。
- **⑦初期費用**: 低。セルフバックで試食レビューも実質低コストで作成可。
- **⑧初回CVの速さ**: 速い（推測）。初回お試しセットが安価（noshは初回1,900円台等）で購入ハードルが低い。
- **⑨AI検索耐性**: 中。「制限食×アレルギー×家族構成」の個別最適化ニーズは強いが、比較検討フェーズ自体はAIチャットに流れるリスクもある（確認不能、推測）。
- **規約リスク**: 軽い。食品表示法・景品表示法の一般順守で足り、薬機法のような重い規制はない。

### 2.2 ペット　総合71点

- **①競争密度**: 中。SERP上位（マイベスト以外はスターシードッグフード調査隊、dekawan.jp、獣医師監修メディア等）は専業特化メディアが多く、犬種・悩み特化キーワードは個人でも上位を取りやすい構造。
- **②単価**: 確認済み。A8.netのペット案件は約160件（ドッグフード約50件、キャットフード約23件）。単価は2,000〜5,000円程度が多いとの二次情報（例: カナガンはA8.netで2,400円、afbでは3,690円）。ASP間で単価差がある点に注意。定期購入は初回のみCV対象のケースが多いと推測。
- **③購買意図**: 「ドッグフード おすすめ 大型犬」「カナガン モグワン 比較」等、犬種・年齢・アレルギー特化のCommercial Investigationが強い。
- **④更新頻度**: 中。新商品サイクルは食品ほど速くないが、犬種・年齢・疾患別の切り口は普遍的で陳腐化しにくい。
- **⑤独自データ**: 高。成分DB（粗タンパク/脂質/繊維、グレインフリー可否、原産国）、価格/kg比較、犬種×体重×アレルギー別レコメンドロジックは獣医師監修と組み合わせれば強い差別化になる。
- **⑥Claude Code適性**: 高。成分表の定型フォーマットが多く自動抽出と相性が良い。
- **⑦初期費用**: 低〜中（実際に与えて反応を見るレビューを行う場合はサンプル購入費が発生）。
- **⑧初回CVの速さ**: 速い部類（推測）。犬種・悩み特化ロングテールが取りやすい。
- **⑨AI検索耐性**: 中。個別相談型クエリはAIに流れやすいが、「実際に与えた継続レビュー」という一次体験データはAIが生成できない。
- **規約リスク**: ペットフード安全法による表示義務あり。景品表示法上の誇大な効能表現（「関節に良い」等）は事業者向け規制だが、断定表現は避けるべき。

### 2.3 資格 / スクール / オンライン教育　総合69.5点

- **①競争密度**: 中〜高。「宅建 通信講座 比較」SERP上位はresemom.jp、diamond.jp、agaroot.jp（講座提供企業自身のオウンドメディア＝利益相反）、マイベスト等。マイナー資格ではロングテールの余地あり。
- **②単価**: 確認済み。A8.net「学び・資格」カテゴリで新規申込5,000円（セルフコース）〜20,000円（マンツーマンコース）の段階報酬を確認。同一講座でもASP間（afbはもしもの1.5倍超等）で単価差あり。
- **③購買意図**: 高い。「宅建 通信講座 比較」「おすすめランキング」は受験申込前の明確なTransactional検索。
- **④更新頻度**: 中（合格率発表年1回、価格改定・早割キャンペーン）。
- **⑤独自データ**: 中〜高。独自アンケート（合格率・満足度・挫折率）を継続収集すれば模倣困難な資産になるが、一次収集コストが必要。単なる公式数字の転記は差別化にならない。
- **⑥Claude Code適性**: 高。価格改定・キャンペーン監視、競合記事差分監視は自動化しやすい。
- **⑦初期費用**: 中。専門性訴求（実際の受験・合格）が説得力に直結し、間接コストが発生し得る。
- **⑧初回CVの速さ**: やや遅い（学習投資は検討期間が長い）が、高単価のため少数CVでも収益化しやすい。
- **⑨AI検索耐性**: 中。「独学 可能か」等はAIに代替されやすいが「講座別合格率」の実データは差別化になる。
- **規約リスク**: YMYL要素あり（人生設計・キャリア投資）だが職業紹介ほどの重い法規制はない。景品表示法上、合格率等の数値は出典明記必須。

### 2.4 AI / SaaS（個人・中小向けAIツール）　総合68.5点（構造的リスクにより実質60前後）

- **①競争密度**: 中。「ChatGPT Plus vs Claude Pro」等のSERPは中小規模の専門ブログ・コーポレートオウンドメディア中心で大手ポータルの支配は他ジャンルより弱いが、更新頻度が極めて速く継続更新できない個人は数ヶ月で陳腐化する。
- **②単価**: **重大な制約を確認**。ChatGPT（OpenAI公式）はA8.net等主要ASPにアフィリエイトプログラムが存在しない。Claude Pro等AI・ITツール系案件は500〜3,000円程度と個人ブログで紹介されるが一次情報未確認。実際に案件があるのは「AIツールの周辺」（画像生成・AIライティング・議事録ツール等のSaaS）が中心と推測される。
- **③購買意図**: 中。比較検索は存在するが「使い方」等のInformational比率が高くTransactional比率は他ジャンルより低い可能性。
- **④更新頻度**: 高（モデル・プラン・料金体系が数ヶ月単位で変動）。
- **⑤独自データ**: 中〜低。実測ベンチマーク（日本語精度、コーディング精度等）は差別化になり得るが検証工数・API費用が個人には負荷が高い。
- **⑥Claude Code適性**: 非常に高い（自己言及的だが、新モデル監視・料金改定監視との親和性は最高）。
- **⑦初期費用**: 低。
- **⑧初回CVの速さ**: セルフバックは即日可能だが第三者への外部CVは中速。
- **⑨AI検索耐性**: **最低水準**。「ChatGPTとClaudeどちらが良いか」はAI自身が最も答えやすい質問領域であり、構造的にAI検索代替リスクが最大。
- **総括**: Claude Code運用との親和性は最高だが、肝心のAIツール本体に案件がなく、かつAI検索代替リスクも最大という構造的ジレンマを抱える。

### 2.5 格安SIM / 通信　総合66.25点

- **①競争密度**: 中〜高。マイベスト、マイナビニュース、エックスモバイル等の企業運営比較特化メディアが上位を占め、A8.net自身が「単純なコンテンツでは成果につながりにくい」とコモディティ化を認めている。超ロングテール（エリア×用途）に活路。
- **②単価**: 確認済み。楽天モバイル（A8.net）通話SIM新規申込1,851円・データSIM925円。他社事例（二次情報）：おとくケータイ.net 5,500〜10,000円、BIGLOBEモバイル953〜2,800円等。**「楽天」「楽天モバイル」等キーワードでのリスティング広告はNG**（自然検索SEOのみ）という規約制約を確認。
- **③購買意図**: 高い。「乗り換え」「最安」型のTransactional検索が主体。
- **④更新頻度**: 高（月次〜随時のプラン改定・キャンペーン変更）。
- **⑤独自データ**: 中〜高。容量帯別・エリア別料金、セット割条件、MNP手数料等の構造化DBが作りやすい。
- **⑥Claude Code適性**: 高（各社公式の料金表・キャンペーンページは構造が単純で定期スクレイピングに向く）。
- **⑦初期費用**: 低。
- **⑧初回CVの速さ**: 比較的速い（単価が高く購入直前検索も多い）。
- **⑨AI検索耐性**: 低〜中（AI Overview表示時、検索1位ページへの流入が58%低下・CTRが34.5%低下という一般論データあり）。シミュレーション性コンテンツで耐性を持たせる必要。

### 2.6 蓄電池・EV充電設備（自治体補助金特化）　総合66点【新規探索ジャンル】

- **①競争密度**: 「一括見積もり」の枠自体（タイナビ、ソーラーパートナーズ）は大手が強いが、**自治体別補助金額を横断整理する専門メディア**という切り口はまだ手薄。
- **②単価**: 確認済み。afbで「家庭用蓄電池・太陽光発電【新日本エネックス】」案件を確認。具体的単価は確認不能。
- **③購買意図**: 高い。「蓄電池 補助金 2026」「EV充電器 設置 補助金 自治体」など極めて具体的な検索。
- **④更新頻度**: **非常に高い**。国の充電インフラ補助金は2026年度予算365億円で継続、戸建てV2H補助金は次回未定など、制度が年度・自治体ごとに頻繁に変わることを確認。
- **⑤独自データ**: **非常に高い**。都道府県・市区町村単位の補助金額・申請期限・併用可否DBは、大手一括見積もりサイトも網羅しきれない粒度になり得る。
- **⑥Claude Code適性**: 非常に高い。自治体HP・経産省/環境省の公開情報の定期クロール・DB自動更新に最適。
- **⑦初期費用**: 低（情報サイトとして開始する場合）。
- **⑧初回CVの速さ**: 中〜遅い（高額商材で検討期間が長い）。
- **⑨AI検索耐性**: 高い。自治体別の最新補助金額はAIも引用・参照しやすい一次情報になり得る。

### 2.7 ガジェット（イヤホン・モバイルバッテリー等）　総合66点

- **①競争密度**: 中〜低。「ワイヤレスイヤホン」「モバイルバッテリー」検索では家電量販店公式に加え個人ガジェットブロガー（カジェログ、note「マクリン」等）の実際の上位表示事例を確認。価格.comのような単一支配サイトが他ジャンルほど強くない。
- **②単価**: Amazonアソシエイトの該当カテゴリは概ね1.0〜1.5%と低め。専業メーカー独自ASP案件の単価は確認不能。物販料率中心のため単価自体は低い。
- **③購買意図**: 高い（型番比較、AとBどっち型のクエリ多数）。
- **④更新頻度**: 高（新規格・新製品が年数回）。
- **⑤独自データ**: 高い。実測（バッテリー実容量、充電速度、装着感等）は価格.comほどの絶対支配的競合が薄く蓄積優位になりやすい。
- **⑥Claude Code適性**: 高（新製品リリース監視、価格変動監視、比較表自動生成）。
- **⑦初期費用**: 低い（6ジャンル中最も検証コストを抑えやすい）。
- **⑧初回CVの速さ**: 比較的速い。
- **⑨AI検索耐性**: 中（実測データを伴えば耐性あり）。

### 2.8 サブスクリプション（動画/音楽/定額）　総合64点

- **①競争密度**: 中。日本語SERPは価格.com等大手も参入するが個人/中小ブログも混在。

- **④更新頻度**: 高（値上げ・キャンペーン頻発）。
- **⑤独自データ**: 中。値上げ履歴・キャンペーン履歴のタイムスタンプDBは他サイトが遡って再現できない。
- **⑥Claude Code適性**: 高。
- **⑦初期費用**: 低。
- **⑧初回CVの速さ**: 中（無料トライアルがある場合は速い）。
- **⑨AI検索耐性**: 低〜中。

### 2.9 婚活アプリ・結婚相談所比較　総合63点【新規探索ジャンル】

- **①競争密度**: 中。AccessTradeに特集ページがあり比較記事は多いが価格.comのような絶対王者は不在。年代別・地域別・目的別の細分化余地あり。
- **②単価**: 確認済み。IBJメンバーズが資料請求で6,000円（税抜）、無料カウンセリングで1,466円（税抜）をAccessTrade経由で提供。ジャンル内では高単価。
- **③購買意図**: 高い（高額サービスのため比較検討必須）。
- **④更新頻度**: 中（キャンペーン、新規アプリ参入、成婚率データ更新）。
- **⑤独自データ**: 高い可能性。総額シミュレーター（入会金+月会費+成婚料）、成婚率と出典の突合、口コミ不満分類は蓄積可能。
- **⑥Claude Code適性**: 高。
- **⑦初期費用**: 低。
- **⑧初回CVの速さ**: 中（資料請求ハードルは比較的低い）。
- **⑨AI検索耐性**: 中（個別条件対応の総額シミュレーションはAIに代替されにくい）。

### 2.10 オンライン家庭教師・個別指導塾比較　総合61点【新規探索ジャンル】

## 4. TOP10 詳細分析

### 第1位: 宅配食/食品宅配

1. **なぜ今参入する価値があるか**: SERP上位が大手ポータル自社サイトでなく専業アフィリエイトメディア中心＝個人が同じ土俵で戦える構造。noshで確認された初回報酬約3,500円前後という定額型で収益予測が立てやすい。薬機法のような重い規制もない。
2. **具体的なターゲット**: 一人暮らし社会人、共働き子育て世帯、糖質・塩分制限が必要な健康層。
3. **狙うべき検索意図**: Commercial Investigation「宅配食 比較 一人暮らし」「nosh ワタミの宅食 どっちが安い」、Transactional「nosh 初回クーポン」。
4. **独自データ**: メニュー別カロリー/塩分/糖質/たんぱく質、価格/食、初回キャンペーン変遷、送料・解約条件比較。
5. **意思決定ツール**: 「制限条件（糖質量・塩分量・アレルギー）→最適サービス診断」ツール、割引後実質単価シミュレーター。
6. **アフィリエイト案件**: nosh（A8.net/afb、初回報酬約3,500〜3,850円 確認済み）、ワタミの宅食ダイレクト（A8.netセルフバックあり）、食宅便（日清医療食品）。
7. **Claude Codeに任せる仕事**: 各社メニュー・価格ページの定期取得と構造化、キャンペーン差分検知、比較表・記事下書きの自動更新、栄養素DBのメンテナンス。
8. **人間がやる仕事**: 実食・実食レポート撮影、味・満足度の主観評価、最終的なおすすめ判断とサイト全体の編集方針、法令順守（食品表示法・景表法）の最終確認。
9. **初期費用**: 低（サーバー・ドメイン年1〜2万円＋試食用の食材購入費）。
10. **初回CVまでの現実的な期間**: ロングテールキーワード（制限食×世帯構成等）を先行して仕込めば1〜3ヶ月程度でCVの芽が出ると推測されるが、確定数値ではない（**推測**）。
11. **主なリスク**: 単発CV中心でLTV（継続課金）構築が課題。ASPの正確な承認条件・承認率は未確認。
12. **競合に対する優位性**: 実食できるため一次情報の構築コストが他ジャンルより低く、栄養素×価格の横断DBを継続更新すれば「制限食対応 宅配食診断ツール」に発展できる。

### 第4位: AI/SaaS（個人・中小向けAIツール）※構造的リスクに要注意

1. **なぜ今参入する価値があるか**: Claude Codeとの自己言及的な親和性が最高（新モデル・料金改定の監視自動化が容易）。競争密度も他ジャンルより緩い。
2. **具体的なターゲット**: 個人事業主・中小企業のAI活用検討層、副業でAIツールを試したい層。
3. **狙うべき検索意図**: 「ChatGPT Plus vs Claude Pro」等の比較検索。
4. **独自データ**: 自作ベンチマーク（日本語ライティング精度、コーディング成功率、料金あたりトークン数）。
5. **意思決定ツール**: 用途別（ライティング/コーディング/リサーチ）ツール診断・料金シミュレーター。
6. **アフィリエイト案件**: **ChatGPT/Claude本体には確認できる公式ASP案件が存在しない**。周辺SaaS（画像生成・議事録ツール等）が中心。
7. **Claude Codeに任せる仕事**: 新モデル発表監視、料金改定監視、競合記事差分チェック。
8. **人間がやる仕事**: 実測ベンチマークの検証・実行、記事の専門的な解釈。

5. **意思決定ツール**: 利用データ量・エリア・セット割条件から最適プランを診断するシミュレーター。
6. **アフィリエイト案件**: 楽天モバイル（A8.net）、BIGLOBEモバイル、OCNモバイルONE等（二次情報953〜10,000円）。**「楽天」等のブランドキーワードでのリスティングNG**という規約制約に注意。
7. **Claude Codeに任せる仕事**: 各社料金表・キャンペーンページの定期スクレイピング、差分検知、記事自動更新。
8. **人間がやる仕事**: ASP規約（NGキーワード等）の遵守確認、実際の乗り換え体験レポート。
9. **初期費用**: 低。
10. **初回CVまでの現実的な期間**: 比較的短い（**推測**、単価が高く直前検索も多いため）。
11. **主なリスク**: 大手比較メディアのコモディティ化した競争、AI Overview表示時のCTR低下（一般論58%）。
12. **競合に対する優位性**: キャンペーン改定周期の予測的コンテンツ、超ロングテール（エリア×用途）での差別化。

### 第6位: 蓄電池・EV充電設備（自治体補助金特化）※新規探索ジャンル

1. **なぜ今参入する価値があるか**: 自治体別補助金DBという切り口はまだ手薄で、制度が年度・自治体ごとに頻繁に変わる＝継続監視の価値が非常に高い。AI検索にも一次情報として引用されやすい。
2. **具体的なターゲット**: 戸建て住宅で蓄電池・EV充電器の導入を検討する層、太陽光発電の併設検討層。
3. **狙うべき検索意図**: 「蓄電池 補助金 2026 〇〇市」「EV充電器 設置 補助金」。
4. **独自データ**: 自治体別補助金額・申請期限・併用可否DB（出典URL・最終確認日付き）。
5. **意思決定ツール**: 郵便番号/自治体入力→適用可能補助金一覧表示ツール。
6. **アフィリエイト案件**: afb「家庭用蓄電池・太陽光発電【新日本エネックス】」（確認済み）、タイナビ・ソーラーパートナーズ等の一括見積り案件。
7. **Claude Codeに任せる仕事**: 全国自治体HP・経産省/環境省の定期クロール、補助金DBの自動更新、変更差分の検知。
8. **人間がやる仕事**: 補助金DBの正確性の最終検証、施工業者選定基準の監修、高額商材ゆえの信頼性担保。
9. **初期費用**: 低（情報サイトとして開始する場合）。
10. **初回CVまでの現実的な期間**: 中〜遅い（**推測**、高額商材で検討期間が長いため半年規模の可能性）。
11. **主なリスク**: 一括見積もり枠自体は大手（タイナビ等）が強い。自治体データの継続メンテナンスコストが高い。
12. **競合に対する優位性**: 全国自治体を横断的かつ最新状態で維持できるサイトが少なく、継続更新そのものが参入障壁になる。

### 第7位: ガジェット

1. **なぜ今参入する価値があるか**: 価格.comのような単一支配的比較サイトが他の家電・PCジャンルほど強くなく、個人ブロガーの上位表示実例を複数確認できた。
2. **具体的なターゲット**: ワイヤレスイヤホン・モバイルバッテリー・スマートウォッチの購入検討層。
3. **狙うべき検索意図**: 「型番＋比較」「AとBどっち」。
4. **独自データ**: バッテリー実容量実測、充電速度実測、装着感・ノイズキャンセリング実測。
5. **意思決定ツール**: 用途（通勤/スポーツ/在宅ワーク）別のガジェット診断・比較表。
6. **アフィリエイト案件**: Amazonアソシエイト該当カテゴリ1.0〜1.5%、楽天アフィリエイト。専業メーカー独自案件は要確認。
7. **Claude Codeに任せる仕事**: 新製品リリース監視（メーカー公式・プレスリリースRSS）、価格変動監視、比較表自動生成。
8. **人間がやる仕事**: 実機の実測作業（バッテリー・充電速度計測等）、装着感等の主観評価。
9. **初期費用**: 低い（6ジャンル中最も検証コストを抑えやすい）。
10. **初回CVまでの現実的な期間**: 比較的早い（**推測**、価格.comの支配が薄いニッチ商品を狙えば数ヶ月規模）。
11. **主なリスク**: 物販料率自体が低い（Amazon1.0〜1.5%）ため、収益化には記事数・アクセス数が必要。
12. **競合に対する優位性**: 実測値（特にバッテリー実容量・充電速度）は他社が同一機材・同一手法で再現しない限り模倣コストが高い。

### 第8位: サブスクリプション（動画/音楽/定額）

1. **なぜ今参入する価値があるか**: 値上げ・キャンペーンが頻発し継続監視の価値が高い。U-NEXT等一部サービスの単価は確認済みで中堅水準。
2. **具体的なターゲット**: 動画配信サービスの乗り換え検討層。
3. **狙うべき検索意図**: 「Netflix Disney+ どっち」「〇〇 解約」。
4. **独自データ**: 値上げ履歴タイムスタンプDB、キャンペーン履歴DB、配信作品数の時系列推移。
5. **意思決定ツール**: 視聴ジャンル・予算から最適サービスを診断するツール。
6. **アフィリエイト案件**: U-NEXT・DAZN・Hulu・ABEMA等（確認済み単価は前述）。**Netflix・Amazon Prime Videoは案件なし**という致命的制約に要注意。
7. **Claude Codeに任せる仕事**: 料金改定・キャンペーン監視、作品追加/終了の定期チェック。
8. **人間がやる仕事**: 実際の視聴体験に基づくレビュー、値上げ発表時の速報記事の最終確認。
9. **初期費用**: 低。
10. **初回CVまでの現実的な期間**: 中（無料トライアルがあるサービスは比較的速い、**推測**）。
11. **主なリスク**: 最需要検索（Netflix関連）で送客先を失う構造的欠陥。
12. **競合に対する優位性**: 値上げ・キャンペーン履歴のタイムスタンプ付きDBは他サイトが遡って再現できない。

### 第9位: 婚活アプリ・結婚相談所比較※新規探索ジャンル

1. **なぜ今参入する価値があるか**: IBJメンバーズの報酬（資料請求6,000円）を確認済みで単価が高く、高額サービスゆえ比較検討ニーズが強い。
2. **具体的なターゲット**: 30代前後の本気で結婚を目指す層、再婚・シニア婚活層。
3. **狙うべき検索意図**: 「結婚相談所 マッチングアプリ どっち」「婚活 おすすめ 30代」。
4. **独自データ**: 総額シミュレーター（入会金+月会費+成婚料）、成婚率と出典の突合DB、口コミ不満分類。

### 第10位: オンライン家庭教師・個別指導塾比較※新規探索ジャンル

| 60日目の目標 | ロングテールキーワード（制限食×世帯構成等）記事20本超、メニュー比較DBの構築開始 |
| 90日目の目標 | 月間安定CV数の把握、診断ツール（β版）の実装、次ジャンル（ペット等）への横展開検討 |

### B案：バランス型

| 項目 | 内容 |
|---|---|
| 推奨ジャンル | ペット（ドッグフード） |
| 推奨ターゲット | 大型犬・アレルギー持ちの犬を飼う層 |
| 最初の商品/案件 | A8.netペットカテゴリの主要ドッグフード案件（カナガン、モグワン等、単価2,000〜5,000円） |

| 項目 | 内容 |
|---|---|
| 推奨ジャンル | 蓄電池・EV充電設備（自治体補助金特化） |
| 推奨ターゲット | 戸建て住宅で蓄電池・EV充電器導入を検討する層（まずは人口上位10〜20自治体から着手） |
| 最初の商品/案件 | afb「家庭用蓄電池・太陽光発電【新日本エネックス】」等の一括見積り案件 |
| 最初に作るコンテンツ | 「〇〇市 蓄電池補助金2026 完全ガイド」を主要自治体分展開 |
| 独自DB | `MunicipalitySubsidy`（自治体, 対象設備, 金額, 期限, 併用条件, 出典URL, 最終確認日） |
| Claude Codeの役割 | 全国自治体HP・経産省/環境省サイトの定期クロール、補助金DBの自動更新、変更差分検知、記事下書きの自動生成 |
| 人間の役割 | 補助金DBの正確性の最終検証、施工業者選定基準の監修、高額商材の信頼性担保 |
| 初期費用 | 5〜10万円程度（サーバー・ドメイン、自治体データ収集の初期工数、**推測**） |

**総評**: A（宅配食）は最短で収益化の手触りを得るのに適し、B（ペット）は速度と資産性のバランスが良く中期の主力候補になり得る。C（蓄電池・補助金）は初回CVまでの期間は長いが、Claude Codeによる継続監視こそが競争優位の源泉になる設計であり、このプロジェクトが目指す「独自データ＋購買意思決定支援＋継続的市場監視」モデルの体現度が最も高い。**まずA or Bで小さく収益化の型を作り、並行してCのDB構築を進める**のが現実的な進め方と考えられる。

## 6. 不採用にした新規候補と理由

| 候補 | 不採用理由 |
|---|---|
| 介護施設・老人ホーム紹介 | 老人ホーム見積り案件はCV意思決定プロセスが複雑で難易度が高い。マイベスト等大手が本格参入し個人の入り込む余地が小さい。 |
| 引っ越し一括見積もり | 引越し侍・SUUMO・ズバット等の資本力のある大手一括見積もりプラットフォームが既に市場を寡占。集客導線（一括見積もりフォーム自体）で個人が対抗できない。 |
| VPS・レンタルサーバー | アフィリエイター自身をターゲットにした「メタ商材」で最も書き尽くされたジャンルの一つ。独自データを作っても模倣が容易。 |
| ロボアドバイザー・家計簿アプリ | ロボアドは投資助言に近く金融クラスタとYMYL規制が重複。家計簿アプリは口座連携の実測データを個人が継続的に作るのが困難。 |

## 7. 確認できなかった重要事項（総括）

本調査全体を通じて、以下は「確認不能」として扱い、数値を推測で埋めていない。参入判断前に必ず一次確認すること。

1. **各ASP（A8.net、もしもアフィリエイト、バリューコマース、Amazonアソシエイト、楽天アフィリエイト、afb、アクセストレード、JANet等）の会員ログイン後にしか見えない正確な単価・承認率・独占案件・キャンペーン頻度**。本調査は非会員向け公開情報・二次情報の範囲に限定されている。
2. 転職ジャンルの2026年8月時点の実際のSERP上位10サイトの具体的な顔ぶれ（一般論の裏付けに留まる）。
3. Claude Pro/Gemini等主要AIサービス自体の公式アフィリエイト提携有無。
4. 音楽サブスク（Spotify、Apple Music等）の単価。
5. ガス事業法における媒介規制の詳細（電気事業法側のみ確認）。
6. クレジットカード・金融アフィリエイトにおけるASP個別の「金融商品」カテゴリ規約（実績要件・監修者要否の明文規定の有無）。
7. 楽天ふるさと納税のアフィリエイト報酬率の具体数値。
8. ふるさと納税の広告規制（2024年10月施行）が個人アフィリエイトブログの記事表現にどこまで具体的に適用されるかの公的ガイドライン。
9. 主要OTA・EC・比較サイトのスクレイピング可否（利用規約上の明確な許諾・禁止）。独自DB構築の実行可能性に直結するため、着手前の確認が必須。
10. 補聴器ジャンルにおけるアフィリエイト案件の実在有無。
11. Amazonアソシエイトの「紹介料上限廃止」の詳細な適用条件・実質的な上限額。
12. 楽天アフィリエイトの正確な「基本カテゴリ料率」表（今回はブログ推定値と期間限定の「料率アップショップ一覧」が混在し、公式基本料率そのものは特定できず）。
