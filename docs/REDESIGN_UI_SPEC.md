## 0. 現状把握（再設計の起点）

現行のCSSは`tools/sitegen/templates.py`の`page_header()`内に1つの`<style>`ブロックとして存在し、以下の特徴を持つ。

- カラーは`--primary:#e8552d`（オレンジ）・`--text:#222`・`--bg:#faf7f5`・`--card:#fff`・`--muted:#666`の5変数のみ。
- タイポグラフィは`h1/h2/h3`の`font-size`のみ定義され、weight・line-height・レター階層の設計は無い。
- `.card`が唯一のコンテナ単位で、情報の重要度に関わらずすべて同じ見た目（`border-radius:8px`・薄い影1種類）。
- ボタンは`.btn-primary`/`.btn-secondary`の2種のみで、hover/active/focusの状態設計が無い。
- spacing・radius・shadowはCSS内に散発的な直値（`12px`, `16px`, `24px`等）が個別に書かれており、スケールとして統一されていない。
- motion（transition）は一切定義されていない。

これは「装飾が少ない」のではなく「デザインシステムが存在しない」状態である。1章以降で、このCSS全体をトークン設計から作り直す。

## 1. Design Principles

1. **データの正直さを視覚で裏切らない**：確認済み・算出値・確認中・未収集は、常に異なる見た目（色・アイコン・濃淡）で表現し、どれか1つでも他より「良く見える」加工をしない。「確認済み＝おすすめ」という混同を色設計・配置設計のいずれでも作らない。
2. **情報階層を強度で表現する**：1ページに強調要素を1つか2つに絞る。すべてを太字・すべてをカード化・すべてを色付けすると、階層が消える。
3. **意思決定に必要な情報を最短距離に置く**：長い説明文より先に「向いている人」「価格」「CTA」に到達できる並び順にする。
4. **競合の情報設計をベースラインにし、独自の検証資産を主役にする**：比較の型（一目で分かる比較表・条件別導線・向いている人の早期提示）は競合水準に合わせるが、そこに乗せる中身（値単位の出典・確認日・検証カバレッジ）は当サイト固有のまま変えない。
5. **抑制されたモーション**：状態変化（hover・選択・フィルタ）にのみ短いtransitionを使う。演出目的のアニメーションは使わない。
6. **モバイルは縮小コピーではなく別設計**：情報密度・CTAの位置・比較表の操作方法をモバイル基準で個別に決める。

## 2. Design Tokens

既存の5変数を、意味の異なるトークン体系に拡張する。**値そのものはCSS変数として定義するのみで、data/config/生成ロジックには一切触れない**（今回はトークンの設計のみで、`<style>`ブロックへの実装は次フェーズ）。

### 2.1 Color

```css
:root {
  /* ブランド（既存の#e8552dを維持。再ブランディングはしない） */
  --color-primary: #E8552D;
  --color-primary-hover: #C8431F;
  --color-primary-active: #A8371A;
  --color-primary-subtle: #FDEEE8;   /* 主CTA周辺の淡い背景・強調パネル用 */

  /* ニュートラル（テキスト・境界線・背景の階層） */
  --color-text: #1F2328;
  --color-text-muted: #5B6470;
  --color-text-faint: #8A9099;
  --color-border: #E7E2DB;           /* --bgの色温度に合わせた暖色寄りグレー */
  --color-border-strong: #D3CCC1;
  --color-bg: #FAF7F5;               /* 既存を維持 */
  --color-surface: #FFFFFF;          /* カード等の面 */
  --color-surface-alt: #FFF8F0;      /* 強調パネル（結論・キャンペーン等）の背景 */

  /* 検証状態（既存4状態のセマンティックカラー。意味は一切変更しない） */
  --status-confirmed-fg: #1E7E34;
  --status-confirmed-bg: #E6F4EA;
  --status-derived-fg:   #1A56DB;
  --status-derived-bg:   #E8F0FE;
  --status-pending-fg:   #B45300;
  --status-pending-bg:   #FFF4E5;
  --status-uncollected-fg: #6B7280;
  --status-uncollected-bg: #F1F1F1;

  /* 全項目確認済みバッジ（既存方針：★や金色は使わない。primaryの輪郭のみ） */
  --badge-full-fg: var(--color-primary);
  --badge-full-border: var(--color-primary);
}
```

**使用ルール**（原則6章5節「確認済み＝おすすめにしない」を担保する制約）:
- `--status-confirmed-*`は「検証状態バッジ」以外の場所（CTAボタンの色、カードの縁取り等）に転用しない。確認済みサービスのカードを緑で囲う、といった実装は禁止。
- `--color-primary`はCTA・主要見出し・目的別導線チップ等「行動喚起」の意味にのみ使う。「おすすめ」を暗示する装飾（星・王冠・金色）は使わない。

### 2.2 Typography

```css
:root {
  --font-family: "Hiragino Kaku Gothic ProN","Noto Sans JP","Yu Gothic",system-ui,sans-serif;

  --text-display: 700 1.875rem/1.3 var(--font-family);   /* 30px, TOPのHeroのみ */
  --text-h1:      700 1.5rem/1.35 var(--font-family);    /* 24px, ページH1 */
  --text-h2:      700 1.125rem/1.4 var(--font-family);   /* 18px, セクション見出し */
  --text-h3:      600 1rem/1.4 var(--font-family);       /* 16px, カード内見出し */
  --text-body:    400 1rem/1.7 var(--font-family);       /* 16px, 本文 */
  --text-body-sm: 400 0.875rem/1.6 var(--font-family);   /* 14px, 補足 */
  --text-meta:    400 0.8125rem/1.5 var(--font-family);  /* 13px, 確認日等のメタ情報 */
  --text-micro:   600 0.6875rem/1.3 var(--font-family);  /* 11px, バッジ・ラベル（letter-spacing:.02em） */

  --price-figure: 700 1.375rem/1.2 var(--font-family);   /* 22px, 価格数値専用（本文より確実に大きく） */
}
```

**階層ルール**: 価格の数値は`--price-figure`で常に本文より一段大きく太くする（現行は本文と同じ`font-size:14px`のテーブルセルに埋没しており、価格が一目で拾えない）。確認日・出典リンクは常に`--text-meta`以下に固定し、本文と同じ強さで書かない。

### 2.3 Spacing Scale（4px基準）

```css
:root {
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-5: 24px;
  --space-6: 32px;
  --space-7: 48px;
  --space-8: 64px;
}
```

現行CSSの`12px`・`16px`・`24px`の直値はこのスケール内に収まっているため、トークン導入によるレイアウト崩れリスクは低い。8px単位から外れる直値（例: `margin-top:8px`個別指定の乱立）をこのスケール変数の参照に置き換える。

### 2.4 Radius / Shadow / Border

```css
:root {
  --radius-sm: 6px;   /* ボタン・バッジ・チップ */
  --radius-md: 10px;  /* カード */
  --radius-lg: 16px;  /* Hero・強調パネル */

  --shadow-sm: 0 1px 2px rgba(31,35,40,.06);
  --shadow-md: 0 4px 16px rgba(31,35,40,.08);
  --shadow-focus: 0 0 0 3px rgba(232,85,45,.25); /* フォーカスリング。primaryの25%透過 */

  --border-default: 1px solid var(--color-border);
  --border-strong: 1px solid var(--color-border-strong);
}
```

### 2.5 Motion

```css
:root {
  --transition-fast: 120ms ease;
  --transition-base: 180ms ease;
}
```

適用対象: ボタンのhover/active、フィルタチェックボックスの選択状態、診断の選択肢の選択状態、FAQアコーディオンの開閉。**それ以外（ページ読み込み時演出・スクロール連動演出等）には使わない**（17章の禁止事項）。

### 2.6 Breakpoints

```css
/* 単一のモバイル境界を維持（既存640pxを踏襲）。
   3段階ブレークポイント化は11社規模のサイトには過剰なため導入しない。 */
--bp-mobile: 640px;
--bp-narrow: 400px; /* 比較表セル・診断チップの折返し調整用の補助境界 */
```

## 4. Typography Hierarchy（ページ内での使用例）

```
TOPページ:
  --text-display  「宅配食、どれを選べばいい？」（Hero見出し）
  --text-body     Heroの説明文
  --text-h2       各セクション見出し（目的で探す／検証状況／キャンペーン 等）
  --text-h3       目的別カテゴリ名・サービスカードのサービス名
  --price-figure  サービスカードの価格数値
  --text-meta     確認日・出典

比較一覧・詳細・比較・verification:
  --text-h1       ページタイトル
  --text-h2       セクション見出し
  --text-h3       カード/テーブル内の小見出し
  --price-figure  価格セルの数値部分のみ（円マーク込みで大きく）
  --text-body-sm  特徴・pros/cons
  --text-meta     バッジ隣接の確認日・出典リンク
  --text-micro    vstatusバッジ・全項目確認済みバッジの文字
```

**重要な変更点**: 現行は価格セルの数値も「公式確認中」の代替テキストも同じ`font-size`で並んでいるため、視認時に価格が目に入りにくい。`--price-figure`を導入し、価格の数値部分（例:「351」）と単位（例:「円/食」）を分離して、数値だけを大きくする（次章のカード設計で具体化）。

### 7.3 CTAの整理（4章の指示に対応）

現行は11社それぞれに同一の「公式サイトを確認」CTAが横並びで13個以上存在し、行動の焦点が無い。再設計後は、

- **主CTA**：「自分に合う宅配食を探す」（診断ツールへ、`btn-primary`、Hero内に1つのみ）
- **副CTA**：「11社を比較する」（比較一覧へ、テキストリンク+矢印、Hero内に1つのみ）

の2方向に絞り、11社個別の公式CTAはHeroから排除し、ページ下部の「主要サービス一覧」セクション内に留める（現行の位置を維持、Heroとは別の役割として整理するのみ）。

## 8. Trust Panel（検証カバレッジの視覚設計、5章の指示に対応）

現行は`<p>価格・送料・初回キャンペーン 計33項目中 11件を公式一次情報で確認済み...</p>`という1行のテキストのみ。これを「デザイン上の主役」にする。

```
┌────────────────────────────────────────────────────┐
│  検証カバレッジ                                       │
│                                                      │
│   11社          33項目          11件                 │
│   掲載サービス数   確認対象の総数    公式一次情報で確認済み │  ← 数値を大きく(--price-figure相当)、
│                                                      │     ラベルを--text-metaで小さく
│  ██████████░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  │  ← 横棒（4状態を色分けしたスタック）
│  確認済み(緑)11 算出値(青)2 確認中(黄)1 未収集(灰)19    │  ← 凡例、状態色のみ使用
│                                                      │
│  → 全社の確認状況を一覧で見る                          │
└────────────────────────────────────────────────────┘
```

**制約の再確認**: この棒グラフ・数値強調は「情報の見つけやすさ」のためのみに使う。特定サービスを目立たせる用途には転用しない（このパネルはサイト全体の集計であり、個社の優劣を示すものではない）。「確認済み11件」を大きく見せることと「だからこのサイトはおすすめ」を結びつける文言は使わない（既存の禁止事項を維持）。

同一のパネル構造を`ranking.html`（比較一覧）冒頭・`verification.html`冒頭でも使う（コンポーネントとして共有、11章参照）。

## 9. Service Card（比較一覧のカード設計、7章の指示に対応）

「border付きdivをカードと呼ばない」という指示に対応し、以下の階層を持つカードを設計する。

```
┌──────────────────────────────────────────┐
│ [シェフの無添つくりおき]  [3項目とも確認済み]  │  ← Header行：サービス名(--text-h3) + 全項目確認済みバッジ（該当時のみ）
│ 無添加  冷蔵  惣菜                          │  ← タグ（現行維持、視覚は--text-micro化）
│                                            │
│  1,035円/食                 [確認済み✓]     │  ← 最重要数値：--price-figureで大きく。バッジは右寄せで並置
│  出典を見る（確認日: 2026-08-26）             │  ← --text-meta、価格の直下に小さく
│                                            │
│  初回26%OFF                  [確認済み✓]    │  ← キャンペーン：価格より一段小さい強調
│  冷蔵・保存方法                              │  ← 保存方法：アイコン＋テキスト（アイコンは統一書体記号、絵文字系1種に統一）
│                                            │
│  健康志向・時短・無添加・家族                 │  ← 向いている人（tags/target要約、--text-body-sm）
│                                            │
│  [詳しく見る]              [公式サイトを確認] │  ← Footer：secondary（左） / primary（右）
└──────────────────────────────────────────┘
```

### 9.1 視覚階層の優先順位（4章「価格→選択条件→信頼性→CTA」を反映）
1. サービス名（identity）
2. 価格（最重要数値、`--price-figure`）
3. 保存方法・向いている人（選択条件）
4. 検証状態バッジ・出典（信頼性、常に価格より小さく・控えめな配色）
5. CTA（行動）

### 9.2 「0.5〜1秒で把握できる」ための規則
- 1カードにつき`--price-figure`は1箇所のみ（価格以外を大きくしない）。
- vstatusバッジは常に`--text-micro`（11px相当）に固定し、本文を上回るサイズにしない。
- カードの背景・境界線はニュートラル（`--color-surface`+`--border-default`）を維持し、確認状態によってカード自体の背景色を変えない（「確認済み＝目立つ緑カード」を禁止）。

### 9.3 比較一覧ページ全体のレイアウト

情報を全部同じ強さで出さないという指示に対応し、以下の3ゾーンに分ける（`FINAL_REDESIGN_SPEC.md`で確定済みの構成要素を、視覚階層として再構成するのみ）。

```
Zone 1: 目的で探す（Purpose Chips、7章のTOPと共有コンポーネント）
Zone 2: 検証カバレッジ（Trust Panel、8章と共有コンポーネント）
Zone 3: 保存方法フィルタ（既存チェックボックス、UIのみ視覚強化）
Zone 4: 比較テーブル or Service Cardグリッド（10.1節で判断）
```

### 9.4 テーブル vs カードグリッドの判断

`REDESIGN_COMPETITIVE_AUDIT.md`で確認済みの通り、**比較目的にはテーブル型がカード型より適する**というCRO知見がある一方、9章の指示は「Service Cardを本気で設計する」ことを求めている。両立方針として、

- **デスクトップ（640px超）**: 現行のテーブル構造を維持しつつ、セル内の価格数値を`--price-figure`で強調し、行間・パディングをspacingスケールに合わせて再設計する（テーブルの列比較性を保ったまま視覚階層を作る）。
- **モバイル（640px以下）**: 現行の「横スクロールテーブル」ではなく、**1サービス=1 Service Cardの縦積みグリッド**に切り替える。ここでのカード化は「9.4節で設計したService Card」そのものを使うため、13章「モバイルでの比較表カード化を禁止」という過去の判断とは矛盾しない——過去に禁止したのは**多列比較表の代替としての簡易カード**であり、今回設計するService Cardは情報階層を持つ本格コンポーネントである点が異なる。この判断の妥当性は15章で明記する。

## 10. CTA Hierarchy（詳細設計）

| 種別 | 見た目 | 使用場面 | 状態設計 |
|---|---|---|---|
| Primary Button | 塗り（`--color-primary`）、白文字、`--radius-sm`、`padding: 12px 24px` | 公式サイトへのCTA、診断ツールへの主導線 | hover: `--color-primary-hover`＋`transform:translateY(-1px)`／active: `--color-primary-active`＋`transform:none`／focus: `--shadow-focus` |
| Secondary Button | アウトライン（`1px solid var(--color-border-strong)`）、`--color-text`文字、透明背景 | 内部回遊（詳しく見る・比較する 等） | hover: 背景`--color-surface-alt`／focus: `--shadow-focus` |
| Text Link | 下線なし、`--color-primary`文字 | 出典リンク・「もっと見る」類 | hover: 下線表示 |

**サイズ規定**:
- Primary/Secondaryボタンの最小タップ領域: 高さ44px以上（モバイルのタップしやすさ、14章）。
- 1カード・1セクションあたりのCTA密度は、既存方針（サービス詳細ページCTA3回等）を変更しない。今回はCTAの「見た目」のみ再設計する。
