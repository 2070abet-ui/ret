## 2. 調査方法

- 2026-08-26時点で18クエリ以上を実測（DuckDuckGo HTML / Bing RSS / Brave / Google）

- 個人サイト参入可能性はS/A/B/Cの4段階で評価

  - A: 個人サイトが4〜10位
  - B: 個人サイトが11〜20位
  - C: 個人サイトがほぼ存在しない

## 調査上の限界（正直な申告）

- **検索ボリューム**: 各KWの正確な検索ボリュームはASP・Googleキーワードプランナー非ログインでは実測不可のため「不明」として扱った。採否はSERP構造と意図で判断。
