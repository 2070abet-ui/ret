## 1. Executive Summary

現在の宅食図鑑は、「宅配食をデータで選ぶ」という**良いコンセプト**を持っているが、その約束を現在のコンテンツがまだ裏付けていない状態。

- **強み**: 独自DB設計（11サービス・キャンペーン・栄養・送料）、最終確認日明記、A8提携5案件のCTA設置済み、診断ツール・比較ページ・記事という導線の原型がある。記事1は「実食していないことを明言し、公式情報だけで検証する」誠実なスタンスで、個人サイトの信頼構築として正しい方向。
- **最大の弱点（P0）**: 全11サービスの詳細ページ・ランキング・キャンペーン一覧に、**アフィリエイトの内部管理情報（ASP・報酬額・承認状態）が一般ユーザー向けに表示されてしまっている**。これは「このサイトは報酬の高いサービスを勧めているのでは」という不信を直接生む。サイトの最も重要な資産である「中立性・信頼」を自ら毀損している。
- **2番目の弱点**: 「実データで比較」を謳うが、ランキング表の最安料金は11社中10社が「要確認」、栄養DB（menus.json）は0件、送料DBは3社のみ。**約束と実態のギャップが大きい**。
- **3番目の弱点**: 内部リンクが極めて薄い。比較ページ→サービス詳細、診断ツール→サービス詳細、サービス詳細→関連サービス、という「サイト内を回遊させる」リンクがほぼ存在しない。「検索流入→1ページ読んで離脱」になる構造。
- **競合との差**: 上位の個人サイト（takushoku-repo.com 等）は「実食×写真」「目的別ランキング」「キャンペーンハブ」で差別化している。当サイトは「データベース型」で差別化しようとしているが、**データが未収集のため現時点では差別化要因になっていない**。

**結論**: 次にやるべきことは「記事を増やす」ことではなく、以下の3点。
1. 内部管理情報の公開表示を止める（信頼回復）
2. 既存DBを実際の数値で埋めて「データで選ぶ」を本物にする
3. サービス詳細→比較→診断→記事の回遊導線を張り直す

## 3. UX監査

### 3.1 第一印象（A）
- ✅ H1「宅配食を、データで選ぶ。」+ 1行説明で「何のサイトか」は3秒で伝わる。サイト名「宅食図鑑」も分かりやすい。
- ⚠️ 「データで選ぶ」と言いながら、すぐ下の主要サービス一覧は「名前+タグ+公式サイトボタン」の羅列で、**データらしきものが見えない**。スクロールしても料金・栄養の数値が出てこない。
- ⚠️ 競合（single-meallife.com の実食写真、takushoku-repo.com の「15社食べて比較」）と比べ、**画像・実体験・独自数値がゼロ**で「また来たい」と思わせる要素がトップに見当たらない。
- ⚠️ 11サービスが縦に並ぶだけで、情報量は「多い」というより「平面的」。サービス間の優劣・向き不向きが一目で分からない。

### 3.2 情報量の過不足
- トップ: 少なすぎる（データの実体がない）。
- サービス詳細: 少なすぎる（「要確認」だらけ、料金プランの表が無い）。
- ランキング: 「ランキング」と名乗るが**順位・評価基準・スコアが一切ない**。「一覧表」であって「ランキング」ではない。ユーザーは順位を期待して来るので肩透かし。
- 記事1: 分量・構成は十分（料金プラン表・送料・解約条件・向き不向き）。現状サイトで最も完成度が高い。

### 3.3 信頼して見えるか
- 現時点では**「内部管理情報の露出」が信頼を大きく毀損**。サービス詳細ページに「アフィリエイト報酬（内部管理情報）: A8.net 7,000円 / 提携承認済み」と一般ユーザーに見える形で表示されている。これは「このサイトは7,000円もらえるサービスを優先して勧めている」と読まれても仕方がない。
- ランキングの「初回報酬目安（最大2,750円）」列、キャンペーンの「成果報酬（ASP）」行も同系統の問題。**ユーザーにとっては「報酬」= サイトが貰えるお金 であり、自分への割引ではない**。誤解を生む表示。

## 4. 情報設計監査（B）

### 4.1 トップ→…の導線
- トップ→ランキング→詳細→比較→診断→記事のページは存在する。
- ただし**比較ページ・診断ツールからサービス詳細ページへのリンクが無い**（公式サイトに直行するだけ）。サイト内を「比較→詳細→比較」と往復する動線が切れている。

### 4.2 カテゴリ構造
- 現状カテゴリ（タクソノミー）は**存在しない**。ナビは「おすすめ比較/初回キャンペーン/診断ツール」の3本のみ。
- 「減塩」「無添加」「高齢者」「一人暮らし」「ダイエット」等の**今後狙うテーマを受け止めるページが無い**。診断ツールのチェックボックスに目的はあるが、それがカテゴリ/一覧ページに繋がらない。
- サービス詳細は「サービス」というフラットな層のみ。**テーマ（減塩・無添加・高齢者）という横断軸が無い**ため、テーマKWからの流入を受け止められない構造。

### 4.3 ユーザーが迷わず到達できるか
- 目的別に迷わず行けるページがそもそも無い。「減塩したい」ユーザーがトップから行けるのは診断ツールのみ（チェックに「高齢者」はあるが「減塩」は無い）。「糖質制限」「無添加」もチェック欄に無い。
- **診断ツールの目的チェックと、今後狙うテーマ（減塩・無添加）が不一致**。

## 5. 回遊性監査（C）※最重要

### 5.1 現状の内部リンクマップ

| 起点ページ | 行き先 | 判定 |
|---|---|---|
| トップ | キャンペーン / 診断 / 各サービス詳細 | ○ |
| ランキング | 各サービス詳細 / 診断 / 公式サイト | ○ |
| キャンペーン | 公式サイトのみ | ✗ サービス詳細へのリンク無し |
| サービス詳細 | 記事1（シェフのみ）/ ランキング / キャンペーン | △ 関連サービスへのリンク無し |
| 比較ページ | キャンペーン / 診断 / 公式サイト | ✗ 比較対象のサービス詳細へのリンク無し |
| 診断ツール結果 | 公式サイト / A8リンク | ✗ サービス詳細へのリンク無し |
| 記事1 | サービス詳細 / ランキング / キャンペーン | ○（ただし記事が1本しか無い） |

### 5.2 「検索流入→1ページで離脱」になる箇所
- **キャンペーン一覧から来たユーザー**は、公式サイトへ直行するだけでサイト内の他の情報（詳細・比較・記事）に一切誘導されない。
- **比較ページから来たユーザー**も同様。比較ページは比較の入口のはずが、出口が公式サイトのみ。
- **診断ツールから来たユーザー**は、結果で公式サイト/A8リンクに直行。サービス詳細で「実は口コミが…」と確認する動線が無い。
- **サービス詳細から来たユーザー**は「ランキングに戻る」しか次の行き先がない。類似サービスの比較（「noshを見た人には三ツ星も合うかも」）が無い。

### 5.3 回遊性を高める具体的な不足
1. サービス詳細→「似ているサービス/比較候補」への関連リンク
2. 比較ページ→比較対象各社のサービス詳細へのリンク
3. 診断結果→サービス詳細へのリンク（「詳しく見る」）
4. 記事→関連記事/関連テーマ（記事が増えるまでの間は、記事1→比較・診断・ランキングへの導線が現状の限界）
5. 「関連サービス」「目的別に探す」等の横断リンクブロックが全ページに無い

## 6. CV導線監査（D）

### 6.1 CTAの数
- トップ: 11サービス ×「公式サイト」+ キャンペーンCTA。**多すぎてどれを押せば良いか分からない**（強弱が無い）。
- サービス詳細: 「公式サイトを見る」（btn-primary）+「公式サイトで最新情報を見る」（btn-secondary）の2点。数は適正。
- ランキング: 各行に「公式サイト」。11個。
- 記事1: 結論ボックス・料金表・まとめの3箇所に A8 CTA。**適正かつ自然**（現在のサイトで最も良いCV導線）。
- 診断ツール: 結果に公式サイト/A8リンクのみ。**「詳細を見る」「キャンペーンを見る」等の副次導線が無い**。

### 6.2 CTAの文言
- サービス詳細・ランキングは「公式サイトを見る」のみ。**価値が見えない**。
  - 改善例: 「初回26%OFFで試す」「新規登録で3食無料」「定期初回15%OFFクーポン」など、キャンペーンDBの情報を使えば具体的な価値ベースのCTAにできる（記事1は既にこの書き方）。
- 「今すぐ申し込む」系の強売りは無いが、**「公式サイトを見る」の連打は売り込み感と無個性感の両方を生む**。

### 6.3 ユーザー種類別の導線
- 比較検討ユーザー: 比較ページが2本しか無く、サービス詳細からも到達できない。
- 初心者ユーザー: 診断ツールが存在するが、トップの1ボタンとランキング下部のみで露出が弱い。
- 口コミ確認ユーザー: 記事1のみ。他サービスに口コミ記事が無い。
- **「申し込む」以外の自然な次行動**（比較する・診断する・口コミを見る）が各ページに弱い。

## 8. 独自価値監査（F）

### 8.1 現状: 「情報をまとめただけ」になっている
- サービス詳細 = 公式サイトの特徴・料金の要約。
- ランキング = 公式サイトへのリンク集。

### 8.3 現時点で唯一の独自性
- **「キャンペーンを最終確認日付きで提示する」**（data/campaigns.json の更新仕組み）は、AIがリアルタイムに答えにくく、本サイトの狙い（自社調査）とも合致する。ただし**現在の実データが少ない**（10件中「要確認」が大半）。

### 9.3 当サイトとのギャップ
- 競合は「**実物を見せて経験で語る**」か「**明確な軸で数値を比較**」のどちらかで差別化している。
- 当サイトは「**データで比較する**」を標榜するが、データが未収集。競合のどちらとも被らない独自路線を選んだが、**現時点ではその路線の実体が無い**ため、競合の足元にも及ばない。
- 逆に言えば、**データを埋めれば「最終確認日付きの横断比較」という競合に無いポジションを取れる**（特にキャンペーンの鮮度）。

## 10. 「また見たい」と思わせる仕組み（Phase 3研究）

ユーザーが「他の記事も見てみよう」「ブックマークしよう」「また来よう」と思う理由を、ジャンル横断で整理する。

### ① 独自データ型
- 宅配食11社の料金比較DB、塩分ランキング、タンパク質ランキング、1食単価ランキング、送料比較、冷凍/冷蔵比較、高齢者向け適合度。
- 「どこにも載っていない横断数値」が再訪理由になる。**当サイトの設計はこれを狙っているが、実装がゼロ**。

### ② 診断・検索型
- 「塩分○g以下」「1食○円以下」「高タンパク」「やわらか食」等の条件で絞り込めるツール。
- 診断結果が「自分専用の答え」だとシェア・再訪が起きやすい。
- 当サイトの診断ツールは「目的タグの一致数」のみで、**価格・塩分・栄養のフィルタが無い**。条件の数が少なく、結果が「公式サイトへのリンク一覧」で終わる。

### ③ 更新型コンテンツ
- 「今週のキャンペーン」「初回割引一覧」「最新料金」「新メニュー」「サービス変更情報」。
- 鮮度が命。更新日時を前面に出すほど「また来る理由」になる。
- 当サイトは campaign の仕組みはあるが**公開ページの実データが少なく、毎週更新の実績がまだ無い**。

### ④ 比較・ランキング型
- 明確な評価基準（○点×○項目）による比較。主観のランキングは信頼されない。
- 当サイトのランキングは「基準なし・順位なし」で、この型の最低条件を満たしていない。

### ⑤ ユーザー課題解決型
- 「塩分を抑えたい」「高齢の家族に」「忙しい」「無添加」「高タンパク」「安く済ませたい」という**課題→サービス**の導線。
- 当サイトは診断ツールに課題の入口があるが、**課題を軸にしたカテゴリ・一覧・記事が無い**。

## 最初に何を変えるべきか（3〜5項目）

今後このサイトを、単なる宅配食アフィリエイトサイトではなく「ユーザーが宅配食を選ぶための情報ツール」にするなら、**最初に変えるべきこと**は以下に絞る。

1. **アフィリエイト内部管理情報の公開を止める**
   「アフィリエイト報酬（内部管理情報）」テーブル・ランキングの「初回報酬目安」列・キャンペーンの「成果報酬（ASP）」行を撤去し、「ユーザーが受け取る特典（初回割引・3食無料・送料無料）」の表示に置き換える。**これはサイトの信頼を左右する最優先事項。**（P0-1〜3）

2. **「データで選ぶ」を本物にするため、既存DBの「要確認」を埋める**
   11社の「最安料金・1食単価・送料・解約条件」を公式情報から調査し、ランキングと比較表を実数値で埋める。**約束と実態のギャップを解消する。**（P2-1）

3. **サイト内回遊の導線を張り直す**
   診断ツール結果→サービス詳細、比較ページ→サービス詳細、サービス詳細→関連サービス/目的別カテゴリ、という「次にどこへ行くか」を全ページに持たせる。**「検索流入→1ページで離脱」を防ぐ。**（P0-4, P1-2）

4. **CTAを「お得な価値」で語る**
   「公式サイトを見る」をやめ、「初回3食無料」「初回26%OFF+送料無料」「定期初回15%OFF」など、キャンペーンDBの実値を使ったCTAに変える。**記事1の書き方を全ページに横展開する。**（P1-1）

5. **テーマカテゴリ（減塩・無添加・高齢者）の受け皿を作る**
   今後狙うテーマを、記事ではなく「カテゴリ一覧→該当サービス」という構造で先に用意し、診断ツールのチェック項目もテーマと一致させる。**将来のテーマKW流入を受け止められる土台を作る。**（P2-4, P0-5）
