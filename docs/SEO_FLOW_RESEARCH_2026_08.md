## 2. 重要なSERP観察（判断の根拠）

1. **シェフの無添つくりおきは個人サイトが実際に上位に食い込んでいる**。nako-blog.com（個人ブログ）・kosokoto.com・takushoku-repo.com が公式2ページの直下に並ぶ。商標ロングテール（口コミ/評判/料金）で個人に勝機があることを実証。
2. **減塩・無添加・高齢者のニッチ系は「実食・数値」を武器にした個人/ニッチサイトが上位**。zaitaku-st.com（実食ランキング）・okawari-lab.net が大手の下に割り込んでいる。**「独自の比較軸+実データ」で個人が戦える領域**。
3. **ヨシケイ商標は公式の地域サイト網（yoshikei-tokyo, yoshikei.com, yoshikei-dvlp 等）が多数あり個人は不利**。ただし「ヨシケイ お試し」「食材宅配 比較 ヨシケイ」等の複合語は別。
4. **食楽膳・健康直球便は検索存在感が極小**。ブランド単独では流入が見込めない。ただし減塩・高齢者・やわらか食という「カテゴリKW」経由で発見される構造が正解。
5. **減塩・高齢者KWにはSOMPO（食楽膳親会社）・nosh・三ツ星・lifoodがリスティング広告を出稿**。このKW帯にCV意図の高いユーザーが集まることの裏付け。

## 6. 最終分類（A / B / C）

### A: 今すぐ狙う価値が高い

#### A-1. シェフの無添つくりおき 商標ロングテール
- **KW**: シェフの無添つくりおき 口コミ / 評判 / 料金 / 初回 / お試し
- **なぜ個人に勝機**: SERPで個人レビューブログが公式の直下に並ぶことを実測。公式コンテンツが薄く、参入障壁が低い
- **CV先**: シェフの無添つくりおき（7,000円・全案件で最高単価）
- **既存ページとの関係**: `/services/chef-muten-tukuritoki.html` が既に存在。これを「実食レビュー」「料金・プラン解説」ページへ内部リンクで拡張
- **収益見込**: 商標系はCV率が高く、1CV=7,000円。流入が少なくても収益効率が最良

#### A-2. 減塩・塩分控えめ 宅配食/冷凍惣菜
- **KW**: 減塩 宅配食 おすすめ / 減塩 冷凍 惣菜 / 塩分控えめ 惣菜 宅配
- **なぜ個人に勝機**: zaitaku-st.com（実食・数値比較）等がmy-bestの下に食い込む。**「実データで比較」が効く領域**で、当サイトの比較DB・栄養データ方針と親和性が最高
- **CV先**: 健康直球便（減塩）→ 食楽膳（塩分控えめ）→ シェフの無添つくりおき
- **既存ページとの関係**: `/services/kenko-chokkyokubin.html`・`/services/syokurakuzen.html` に内部リンク。減塩KW記事から直接CV導線
- **収益見込**: 検索量は中だがCV適合が最良。減塩KWに出稿する競合広告（SOMPO/nosh）が存在＝需要の証明

#### A-3. 無添加 冷凍惣菜・おかず宅配
- **KW**: 無添加 惣菜 宅配 / 無添加 冷凍 惣菜 おすすめ
- **なぜ個人に勝機**: okawari-lab.net・happy-trendy.com等のニッチ比較サイトが公式ECと並んで上位。ランキング形式で個人が入れる
- **CV先**: シェフの無添つくりおき（無添加＝コンセプト一致）
- **既存ページとの関係**: `/services/chef-muten-tukuritoki.html` を中心に、ランキングページから誘導
- **収益見込**: シェフの無添7,000円に直結。無添加ニーズは健康意識が高く購入意図も強い

#### A-4. 高齢者向け宅配食（やわらか食・個食・塩分）
- **KW**: 高齢者 宅配食 おすすめ / 高齢者 冷凍 惣菜 / やわらか食 宅配
- **なぜ個人に勝機**: silver-choice.jp・mimamori.website等の高齢者ニッチサイトが上位。my-bestは存在するが、やわらか食・個食・塩分の掛け合わせは未飽和
- **CV先**: 食楽膳（個食・塩分控えめ・SOMPO信頼）→ 健康直球便（やわらか食・減塩）
- **既存ページとの関係**: `/services/syokurakuzen.html`・`/services/kenko-chokkyokubin.html` に直結
- **収益見込**: 高齢化で需要は安定的に拡大。食楽膳は定期40%でLTVが高い

### B: 条件付きで狙う

#### B-1. 食材宅配 おすすめ（ヨシケイ経由）
- **CV先**: ヨシケイ（1,100円）
- **勝機**: coetas.jp等のニッチ比較サイトが上位に入る余地はあるが、my-best・GYROが強い
- **条件**: ヨシケイ報酬が1,100円と低い。**単独では狙わず**、「宅配食×食材宅配」の比較ページ内でヨシケイを1社として扱う形なら有効
- **既存との関係**: `/services/yoshikei.html` は維持し、比較ページからの内部リンクに留める

#### B-2. 一人暮らし 宅配食
- **CV先**: 4案件との適合が弱い（nosh/三ツ星が主役で未提携）
- **条件**: 現時点ではCV効率が悪い。**A-2/A-3/A-4で実績が出てから**、比較コンテンツの一部として追加検討
- **除外根拠**: 流入は見込めるが「CV先がない」テーマ

#### B-3. 糖質制限 宅配食
- **CV先**: 適合なし（nosh/三ツ星が牙城で未提携）
- **条件**: 現状はCV効率が悪い。コンテンツ網羅として1本追加するかは、Aクラスの実績後

## 8. 結論（エグゼクティブサマリー）

1. **最優先は「シェフの無添つくりおき商標ロングテール」**。最高単価7,000円×個人ブログが上位に入る実績あり。最初のCVを最速で取るならここ。
2. **中核の資産化テーマは「減塩・無添加・高齢者」の3ニッチ**。いずれもA8案件（健康直球便・食楽膳・シェフの無添つくりおき）と直結し、**「実データ比較」という当サイトの方針が競合優位になる領域**。
3. **除外するのは「大手が支配するヘッド語」と「CV先がないテーマ」**（一人暮らし・糖質制限）。検索ボリュームだけで狙わない。
4. **商標単独では需要が小さくても、サービスページは維持**し、カテゴリKW（減塩/高齢者等）からの内部リンクで発見される構造にする。

（本調査は2026-08-26時点の実測SERPに基づく。実際の順位変動・検索需要の検証は、記事公開後のGoogle Search Consoleデータで行う。）
