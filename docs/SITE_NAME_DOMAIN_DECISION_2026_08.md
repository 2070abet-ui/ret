## 1. 決定の前提

- 宅配食・宅配弁当・食品宅配を中心とする
- 将来的に宅配食サービスを追加しても違和感がない
- 特定サービス（nosh等）の公式サイトと誤認されない
- 個人運営でも不自然でない
- SEOとブランドの両立
- 比較DB・検索・診断サービスへ拡張可能
- サイト名はASP登録欄の25文字以内
- ドメインは短く・覚えやすく・汎用的に
- 商標・名称混同リスクを確認済み
- ドメイン取得可能性は実確認（RDAP / JPRS whois）

## 6. 今すぐASP登録に使うなら

# 「宅食図鑑」 takushokuzukan.jp

**選定理由**:
1. 競合takushokulab.com（同一ニッチ・稼働中）とブランドが完全に分離できる
2. 「図鑑」＝網羅性・データの含意が、今回の事業方針（比較DB・栄養DB・診断ツールというデータサービス化）に最も合致
3. 覚えやすく独自性が高く、SEOの「宅配食」キーワードはタイトルタグ側で補完できる
4. ドメインが短く（takushokuzukan.jp）、.jp/.comとも取得可能であることを実確認済み
5. 個人運営でも自然で、大企業・既存ブランドとの誤認リスクがない

**推奨ドメイン取得**: 優先「takushokuzukan.jp」、予備「takushokuzukan.com」を併せて取得することを推奨（ブランド保護）。.jpは国内住所・連絡先での申込が必要。

**タイトルタグでのSEO補完例**:
`宅食図鑑｜宅配食・宅配弁当のおすすめ比較と初回キャンペーン情報【2026年最新】`
