## 0. 現状の色面構成（実測）

TOPの主要セクションは4つの色面で構成され、`A-B-[透明]-B-A`の対称反復になっている。

| セクション | CSSクラス | 現在の背景トークン | 実際の色 | 記号 |
|---|---|---|---|---|
| hero | `.hero` | `--color-surface-alt` | #FFF8F0 | A |
| 目的で探す | `.purpose-section-top` | `--color-primary-subtle` | #FDEEE8 | B |
| 主要サービス一覧 | `.service-list-section` | 透明（ページ地色bg） | #FAF7F5 | 透明 |
| 初回キャンペーン | `.campaign-pick` | `--color-primary-subtle` | #FDEEE8 | B |
| このサイトのこだわり | `.section-flat` | `--color-surface-alt` | #FFF8F0 | A |

**問題の本質**: 2色（A=surface-alt、B=primary-subtle）が**各2回ずつ**対称に使われ、透明の一覧を挟んで上下に反復する。特に「目的」と「キャンペーン」が**同色B**で、離れた位置に2回出て「色面を機械的に割り当てた」印象を与える。

## 1. 比較する2案

### 案1：どちらか一方の色面を脱色して透明化

#### 案1a：目的で探す（`.purpose-section-top`）を透明化

- **現状CSS**: `.purpose-section-top { background:var(--color-primary-subtle); border-radius:var(--radius-lg); padding:var(--space-5); margin:0 0 var(--space-4); }`
- **変更対象**: `.purpose-section-top`（358行）とモバイル上書き（568行）
- **変更内容**: `background`を`var(--color-bg)`（ページ地色）に。`border-radius`を`0`に（透明背景では角丸が意味をなさない）。`padding`を上下のみ（`var(--space-4) 0`）に縮小し、色帯としての箱をやめて余白として扱う。
- **視覚的効果**: ファーストビューが「A(hero) → [透明・目的] → 透明(一覧)」になり、heroの色帯を除いて透明ゾーンが続く。目的のチップ（`.purpose-chip`＝`--color-primary-subtle`背景）はそのまま浮き、選択UIとして視認できる。残る色面は hero(A)・キャンペーン(B)・こだわり(A) の3つで、**Bは1回だけ**になる。
- **情報階層への影響**: 目的は「ナビゲーション（チップ群）」であり、セクション色帯なしでもチップが自己完結している。hero（最重要）とキャンペーン（購買導線）が色面として強調され、一覧（透明）への流れがスムーズになる。
- **AI/テンプレート感がなぜ減るか**: 同色ペアが「hero/こだわりのA」1組だけになり、**Bの機械的2回反復が消える**。「A-透明-透明-B-A」は対称だが、2色の等間隔交互反復ではなくなる。
- **PC/700px/375px/414pxへの影響**:
  - PC: 目的の色帯が消え、ファーストビューが明るく（地色に近く）なる。チップは浮いたまま。
  - 700px: 目的は常時展開。透明背景でもチップ・リンクのコントラストは維持（チップはB色背景のまま）。
  - 375px/414px: 目的は折りたたみ（summary表示）。透明背景でsummary「目的で探す ▾」がh2テキストとして読める。
- **回帰リスク**: 中。目的セクションと一覧の境界が「余白のみ」になるため、境界の視認性が下がる可能性。ただしP1の不均一余白（目的下16px・一覧上）とtrust-lineが境界を担保する。チップの色・リンク・折りたたみ・↓アンカーは無変更なので機能は不変。

#### 案1b：初回キャンペーン（`.campaign-pick`）を透明化

- **現状CSS**: `.campaign-pick { background:var(--color-primary-subtle); … }` ＋ P1追加 `.container-top .campaign-pick { margin:0 0 var(--space-7); }`
- **変更対象**: `.container-top .campaign-pick`（P1追加分のスコープ）
- **変更内容**: `background`を`var(--color-bg)`に。
- **視覚的効果**: 残る色面は hero(A)・目的(B)・こだわり(A)。キャンペーンの色帯が消える。ただしキャンペーン内部の`.campaign-pick-main`（白・surface）は残るため、PICK UPカード自体は視認できる。
- **情報階層への影響**: キャンペーンは購買導線（PICK UP・CTA直結）の主役ゾーン。色帯を消すと「お得情報」の強調が弱まり、購買導線が**後退**する可能性がある。
- **AI/テンプレート感がなぜ減るか**: 同色Bが1回（目的のみ）になる。ただし、B（目的）がファーストビューの直下に残り、A-B-A（hero・目的・こだわり）の反復が残る。
- **PC/700px/375px/414pxへの影響**: キャンペーンが透明化される影響は全幅共通。PICK UPカード（白）は残る。
- **回帰リスク**: 中〜高。購買導線（CTA直結のPICK UP）の視覚的強調が減るため、CVに影響する可能性。監査でも「キャンペーンは購買導線のため脱色面化するなら目的を先に」と明記。

### 案2：同色ペアにならないよう既存トークンの割当を変更

- **変更対象**: `.purpose-section-top` または `.campaign-pick` のbackgroundトークン割当（例: 目的を`--color-surface-alt`へ、等）
- **変更内容**: 目的をA色（surface-alt）に、キャンペーンをB色（primary-subtle）のまま → 構成が「A-A-透明-B-A」に。
- **視覚的効果**: 同色ペアは解消するが、**隣接するhero(A)と目的(A)が同色**になる。両者ともクリーム系（#FFF8F0）で、縦に積むTOPでは境界が曖昧になり、かえって「ぼんやりした連続帯」に見える。
- **情報階層への影響**: hero（最重要）と目的（ナビ）が同色で区別しにくくなり、ファーストビューの階層が損なわれる。
- **AI/テンプレート感がなぜ減るか**: 減らない（むしろ悪化）。2色反復は「隣接同色」に形を変えるだけ。
- **PC/700px/375px/414pxへの影響**: heroと目的が同色になるため、全幅で境界が曖昧になる。
- **回帰リスク**: 高。heroと目的の区別がつかなくなり、ファーストビューの視覚的構造が崩れる。

## 3. 推奨案の確定

# **推奨: 案1a（目的で探す`.purpose-section-top`を透明化）**

理由:
1. **最小変更**: `.purpose-section-top`の背景を既存`--color-bg`に変えるだけ（＋角丸・paddingの整理）。
2. **最もテンプレ感を減らす**: 同色B（primary-subtle）の2回反復が消え、色面が「hero(A)・キャンペーン(B)・こだわり(A)」になり、Bは1回だけ。
3. **購買導線を守る**: キャンペーン（PICK UP・CTA直結）の色帯を維持し、CVへの影響をゼロにする。
4. **情報階層を保つ**: 目的の選択UIはチップ（B色背景）が自己完結しており、セクション色帯なしでも機能。heroと一覧の間に透明ゾーンができ、一覧への流れが改善。
5. **監査の結論と整合**: FINAL_VISUAL_AUDIT_2026_08_28.md §2.1 で「キャンペーンは購買導線のため、脱色面化するなら目的を先に」と明記済み。

## 4. 具体的な実装手順（推奨案1a）

`tools/sitegen/templates.py` の `_CSS` のみを変更する。

### 手順1: デスクトップの`.purpose-section-top`（358行）

```css
/* 変更前 */
.purpose-section-top { background:var(--color-primary-subtle); border-radius:var(--radius-lg); padding:var(--space-5); margin:0 0 var(--space-4); }
/* 変更後 */
.purpose-section-top { background:var(--color-bg); padding:var(--space-4) 0 0; margin:0 0 var(--space-4); }
```

- `background`をページ地色`--color-bg`に（＝透明化。body背景と同色になり「色面」が消える）。
- `border-radius`を削除（透明背景では角丸が意味をなさない）。
- `padding`を`var(--space-5)`（24px四方）→`var(--space-4) 0 0`（上16pxのみ）に。色帯としての箱をやめ、チップ群の上部余白のみにする。下marginはP1の`var(--space-4)`を維持。
- コメントを更新（色帯ゾーン → 透明の選択UIゾーン）。

### 手順2: モバイル上書き（568行）

```css
/* 変更前 */
.purpose-section-top { padding:var(--space-4); margin:0 0 var(--space-3); }
/* 変更後 */
.purpose-section-top { padding:var(--space-3) 0 0; margin:0 0 var(--space-3); }
```

- モバイルも同様に「上下のみ・小さめ」の余白に。

### 手順3: 変更しないもの（確認）

- `.purpose-section`（共有クラス）の`margin:var(--space-5) 0` → **変更しない**。
- `.purpose-section-top h2 { font:var(--text-h1) }` → **維持**（見出しの大きさは変えない）。
- `.purpose-section-top .purpose-groups { display:grid; grid-template-columns:1fr 1fr; }`（モバイル2列化）→ **維持**。
- `.purpose-chip`（`--color-primary-subtle`背景）→ **維持**（チップの視認性が選択UIを担保）。
- `.campaign-pick`・`.section-flat`・`.hero`の背景 → **無変更**。
- `purpose_chips_block()`のHTML・リンク・アンカー・折りたたみ（P2-0）→ **無変更**。

### 変更後の色面構成（期待値）

| セクション | 背景 | 記号 |
|---|---|---|
| hero | `--color-surface-alt` (#FFF8F0) | A |
| 目的で探す | **`--color-bg` (#FAF7F5＝ページ地色)** | **透明** |
| 主要サービス一覧 | 透明 | 透明 |
| 初回キャンペーン | `--color-primary-subtle` (#FDEEE8) | B |
| このサイトのこだわり | `--color-surface-alt` (#FFF8F0) | A |

→ **A - 透明 - 透明 - B - A**。Bは1回だけになり、A-B-A-Bの機械的反復が解消される。
